# Third-party projects, models, and data

SoccerBillboardLab is an independent research prototype. It is not an official
component of any project listed below.

## SAM2

- Project: Segment Anything Model 2 (SAM2)
- Repository: https://github.com/facebookresearch/sam2
- Use the official repository, checkpoint source, license, and acceptable-use
  terms that apply to the version you install.
- SAM2 source code and checkpoints are not redistributed here.

## SoccerMaster

- Repository: https://github.com/haolinyang-hlyang/SoccerMaster
- SoccerBillboardLab can consume compatible detection/state output produced by
  SoccerMaster.
- As of 2026-08-29, GitHub's License API did not report a license file for that
  repository. Do not copy or redistribute SoccerMaster source code without an
  applicable license or permission from its authors.
- SoccerMaster source code, models, and state archives are not redistributed
  here.
